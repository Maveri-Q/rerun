# Repair benchmark

Generated by `pnpm repair-benchmark`. Do not edit by hand.

**Not finished: 4 of 5 papers so far, so this proves nothing yet about AI repair (1.5 of 4 repaired).**

Each paper is first run with its packages as of the commit date, using no AI, to get a reference number. It is then broken on purpose by installing today's newest packages, and the real private AI (z-ai/glm-5.3-flash) gets up to 6 tries. A repair only counts if the number matches the reference within 0.5%. Papers that still run on today's packages aren't counted, because they don't test repair.

The first complete run scored 1 of 4. After seeing that, on 2026-11-05, we changed what the AI is shown: it now gets the exact text of the files it edits, because many of its blocked edits were for text it couldn't see. The safety checks on its edits did not change.
